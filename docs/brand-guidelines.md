# Moonbloom Farms Brand Guidelines

## Color System

### Primary Palette

| Color | HEX | Usage |
| --- | --- | --- |
| Deep Farm Green | `#2E3D2F` | Primary logo |
| Moon Cream | `#F4F1E8` | Background |
| Muted Olive | `#5E6F5F` | Secondary |
| Soil Brown | `#6E5C4A` | Accent |

### Optional Accent

Use Antique Gold `#C9A96A` for premium packaging and occasional highlight accents.

## Typography

### Primary Typeface (Logo + Headlines)

Use an elegant serif family.

Preferred order:
1. Canela
2. Cormorant
3. Tiempos
4. Freight Text

### Secondary Typeface (Body + Labels)

Use a clean sans serif family.

Preferred order:
1. Inter
2. Sohne
3. Source Sans 3

## Usage Rules

### Do

- Use monochrome versions.
- Use high-contrast backgrounds.
- Use icon mark independently when needed.

### Do Not

- Stretch logo.
- Rotate logo.
- Recolor petals individually.
- Add drop shadows.
- Outline type.
- Place logo on busy photos.

## Visual Language Tone

Photography should be:

- Natural light
- Shallow depth of field
- Warm tone
- Imperfect textures

Avoid:

- Overly saturated greens
- Glossy stock photography
- Harsh contrast
